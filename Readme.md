# titre de projet:gestion-tache
## Fonctionnalités:
* Ajouter une tâche
* Afficher les tâches
* Rechercher une tâche
* Quitter le programme

## ## Étapes réalisées:
1) Création du dossier du projet
2) Création du fichier main.py
3) Développement du menu principal
4) Ajout de la fonctionnalité d'ajout des tâches
5) Ajout de la fonctionnalité d'affichage des tâches
6) Ajout de la fonctionnalité de recherche
7) Tester le programme avec VS Code
8) Création du fichier README.md
## Méthode d'exécution:
1) Ouvrir Visual Studio Code
2) Ouvrir le dossier du projet
3) Ouvrir le fichier main.py
4) Cliquer sur le bouton "Run Python File"
5) Le programme s'exécute dans le terminal
6) Choisir une option dans le menu pour utiliser l'application
